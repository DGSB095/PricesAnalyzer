## Ozon Seller API

Основная ссылка: [документация Seller API](https://docs.ozon.ru/api/seller/).
Страница открылась, но инструмент проверки не смог извлечь текст её динамической
документации. Для конкретных утверждений проверены официальные материалы Ozon:

- [Seller API FAQ](https://dev.ozon.ru/start/257-Seller-API-FAQ-spravochnik-oshibok-i-sposobov-ikh-resheniia):
  работа с товарами, остатками, отправлениями и отчётами своего продавца;
  для обычной интеграции используются Client-Id и Api-Key с нужными правами.
- [OAuth для Seller API](https://dev.ozon.ru/start/450-Protsess-OAuth-avtorizatsii-dlia-dostupa-k-Seller-API-Ozon/):
  для частных приложений предусмотрен отдельный авторизационный процесс и scopes.
- [Отчёты по вывозу и утилизации](https://dev.ozon.ru/news/595-Rasshirennaia-analitika-po-vyvozu-tovarov-v-Seller-API/):
  официально описаны JSON-ответы методов и аналогичный **Excel-отчёт в кабинете**.
  Это подтверждение конкретного отчёта, не универсального CSV прайс-листа.
- [Изменения отчётов от 18.11.2026](https://dev.ozon.ru/news/844-Novye-metody-polucheniia-otchetov-o-realizatsii-v-Seller-API/):
  актуальный порядок формирования отчётов требует сначала получить номер отчёта;
  методы и доступность меняются, контракт надо проверять перед интеграцией.

Для проекта: возможны загрузка собственного ассортимента и отчётности по разрешению
владельца кабинета. Доступ к полной базе чужих рыночных цен не подтверждён.
Нужны отдельные сопоставление товаров и адаптер конкретного разрешённого отчёта.
Универсальная CSV-выгрузка предложений всего Ozon **не подтверждена**.

## Wildberries API

Официальные ссылки: [портал разработчиков](https://dev.wildberries.ru/),
[общая информация и авторизация](https://dev.wildberries.ru/openapi/api-information),

**Актуальное содержимое проверить не удалось:** портал и указанные страницы
вернули ошибку 498 в инструменте веб-проверки, в том числе английские варианты.
Поэтому точные текущие методы, лимиты, категории токенов и доступные файловые
форматы здесь не объявляются подтверждёнными.

Ориентир для будущей интеграции, требующий повторной проверки: API продавца
предназначен для работы с его карточками, ценами, остатками, заказами и аналитикой;
ожидается кабинет продавца и авторизующий токен с соответствующими правами.
Это не основание обещать доступ к предложениям всех чужих продавцов.
Конкретные CSV/XLSX-выгрузки **в этой проверке не подтверждены**.

Для проекта: сначала получить разрешение владельца кабинета, повторно проверить
официальную авторизацию и выбрать конкретный метод/файл. Не использовать внутренние
API сайта и не заявлять поддержку «CSV Wildberries» без образца и контракта.

## API Яндекс Маркета для продавцов

Проверены [введение](https://yandex.ru/dev/market/partner-api/doc/ru/),
[API-Key](https://yandex.ru/dev/market/partner-api/doc/ru/concepts/api-key),
[получение отчётов](https://yandex.com/dev/market/partner-api/doc/ru/step-by-step/reports)
и [отчёт по реализации](https://yandex.com/dev/market/partner-api/doc/ru/reference/reports/generateGoodsRealizationReport).

API предоставляет управление ассортиментом, ценами, остатками, заказами и отчётами
продавца. Нужен кабинет и API-Key-токен с разрешениями на группы методов; создавать
токены могут уполномоченные роли кабинета. Это интеграция с конкретным бизнесом,
а не открытая выгрузка всех предложений рынка.

Файлы действительно предусмотрены: отчёты генерируются асинхронно, затем API
возвращает ссылку для скачивания. Для **отчёта по реализации** официальная
документация описывает колонки CSV, JSON и XLSX. Форматы надо уточнять для каждого
отчёта; наличие такого отчёта не подтверждает универсальную выгрузку рыночных цен.
Для проекта нужен отдельный адаптер нужного отчёта и разрешённого кабинета.

## Файлы поставщиков

CSV/XLSX или другие файлы подходят, если сам поставщик предоставляет их и разрешает
использование. Единого подтверждённого формата всех поставщиков нет. XLSX в текущем
коде не поддерживается. Наш CSV — собственный документированный контракт,
**не нативная выгрузка Ozon, WB или Яндекс Маркета**.

При подключении конкретного поставщика нужно согласовать идентификаторы товара,
единицы, валюту, дату наблюдения и смысл пустых значений. Его файл преобразуется
в собственный CSV либо в Observation. Товары нельзя автоматически объединять по
похожему названию. Учебные записи из `data/sample_offers.csv` не отражают рынок.

## HTML-парсинг и Books to Scrape

Проверены [Books to Scrape](https://books.toscrape.com/) и
[описание учебной площадки](https://toscrape.com/). Сайт создан для практики
парсинга, не требует авторизации. Цены и рейтинги демонстрационные и не имеют
рыночного смысла. Подтверждён именно HTML-каталог, не официальная CSV-выгрузка.

Адаптер делает HTTP-запросы Requests и извлекает данные Beautiful Soup.
Есть пауза 0,5 секунды, максимум 3 попытки временных сбоев на страницу,
предел страниц, запрет перехода на чужой домен и проверка циклов пагинации.
Изображения не скачиваются. Единственный поставщик — сам учебный магазин.
Условия доставки, минимальной партии и дополнительные расходы неизвестны.

Переход к другому магазину потребует отдельной проверки правил автоматизированного
доступа, структуры страниц и качества данных. Этот парсер не универсален и
не обходит CAPTCHA, авторизацию или ограничения доступа.
